Plan Found

The active plan is the Hit Zero quality/audit hardening plan, not the older routine-builder plan. Its main rule is the Click Contract: every visible action must navigate somewhere real or perform a real, awaited mutation; success must refresh real data; failure must show a specific error; and live mode must not silently write only to local demo state.

The plan also calls for route inventory, frontend code audit, Supabase/RLS review, data cleanup, integration checks, privacy review, and a repeatable regression harness.
